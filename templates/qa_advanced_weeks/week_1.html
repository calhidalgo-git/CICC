Pruebas de rendimiento: velocidad y estabilidad bajo carga

Las pruebas de rendimiento buscan evaluar cómo responde un sistema cuando se enfrenta a diferentes niveles de demanda.

  • Velocidad: mide el tiempo de respuesta de la aplicación ante solicitudes de los usuarios.
  • Estabilidad: analiza si el sistema mantiene un comportamiento consistente bajo cargas prolongadas.
  • Tipos principales:
    • Pruebas de carga: simulan usuarios concurrentes para verificar capacidad.
    • Pruebas de estrés: llevan el sistema al límite para identificar puntos de falla.
    • Pruebas de escalabilidad: validan si el sistema puede crecer en recursos sin perder rendimiento.
  • Ejemplo: usar JMeter para simular 1,000 usuarios accediendo a un portal de e-commerce al mismo tiempo.

Pruebas de seguridad: detección de vulnerabilidades (SQL Injection, XSS)

El objetivo es garantizar que el software sea resistente frente a ataques maliciosos.

  • SQL Injection: ocurre cuando un atacante inserta código SQL en campos de entrada para manipular la base de datos.
  • XSS (Cross-Site Scripting): se da cuando un atacante inyecta scripts en páginas web, afectando a otros usuarios.
  • Herramientas: OWASP ZAP, Burp Suite.
  • Importancia: la seguridad es crítica en aplicaciones modernas, especialmente en sistemas financieros, de salud o comercio electrónico.
  • Ejemplo: probar un formulario de login con entradas maliciosas para verificar que el sistema las rechace.

Pruebas de usabilidad: experiencia del usuario y accesibilidad

Estas pruebas se centran en la interacción del usuario con el sistema.

  • Experiencia del usuario (UX): evalúa si la aplicación es intuitiva, clara y fácil de usar.
  • Accesibilidad: asegura que personas con discapacidades puedan utilizar el software (ej. lectores de pantalla, navegación por teclado).
  • Normas: WCAG (Web Content Accessibility Guidelines).
  • Ejemplo: verificar que un sitio web tenga contraste adecuado de colores y que los formularios puedan completarse con teclado sin necesidad de mouse.

Pruebas de compatibilidad: validación en distintos dispositivos y navegadores

El objetivo es garantizar que el software funcione correctamente en diversos entornos.

  • Dispositivos: PC, tablets, smartphones.
  • Sistemas operativos: Windows, macOS, Linux, Android, iOS.
  • Navegadores: Chrome, Firefox, Safari, Edge.
  • Importancia: los usuarios acceden desde múltiples plataformas, por lo que la compatibilidad asegura una experiencia uniforme.
  • Ejemplo: validar que una aplicación web se visualice correctamente en Chrome y Safari, tanto en escritorio como en móvil.
